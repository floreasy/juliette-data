# juliette.data

Site de Juliette Spinnato, consultante en Science des données et IA à Marseille.

Site statique : une page HTML par page du site, une feuille `styles.css`, un
script `site.js`, les polices dans `fonts/`, le portrait dans `images/`.
Aucune étape de construction : le dépôt se sert tel quel (GitHub Pages, nginx…).

- Charte et maquettes : `~/dev/marie-flow/clients/juliette-data/`
- Domaine prévu : juliettedata.fr
